# Воркер API (artyomcut-api)

Здесь лежит обновлённый код воркера. Он не содержит секретов: пароль админки и
хранилища задаются в настройках Cloudflare (переменные и биндинги), а не в коде.

## Что изменилось по сравнению с прежней версией

1. **Правильные коды ошибок.** Невалидные данные (пустое имя, прошедшая дата,
   выходной, время вне графика, кривой JSON) теперь возвращают `400` с понятным
   текстом, а не `500 Internal server error`. Дубликат слота — `409`.
2. **Исправлена потеря записей.** Раньше все записи хранились одним JSON-списком в
   одном ключе KV: две одновременные записи перезаписывали друг друга, и одна
   терялась (оба клиента при этом видели «успех»). Теперь:
   - каждая запись — отдельный ключ `booking:<id>`;
   - слот занимается отдельным ключом `slot:<дата>:<время>` с подтверждением
     после записи;
   - при одновременной записи на один слот ровно один получает `200`, остальные —
     `409 «Это время уже занято»`.
3. **Совместимость.** Старый ключ `bookings` читается один раз при первом запросе
   и автоматически переносится в новый формат. Админка и `/api/booked` работают
   как раньше, менять фронтенд не нужно.

## Как задеплоить

1. Cloudflare Dashboard → **Workers & Pages** → `artyomcut-api`.
2. **Edit code** (Quick edit).
3. Выделить весь код в редакторе → вставить содержимое `worker.js` целиком.
4. **Deploy** (Save and deploy).

Биндинги (`ARTYOMCUT_DATA`, `ARTYOMCUT_BUCKET`) и переменную `ADMIN_PASSWORD`
трогать не нужно — они живут в настройках воркера, а не в коде.

## Проверка после деплоя

```bash
# невалидные данные → 400
curl -i -X POST https://artyomcut-api.vasia-pupkin1003.workers.dev/api/bookings \
  -H "Content-Type: application/json" -d '{}'

# список записей (нужен токен админки)
TOKEN=$(curl -s -X POST https://artyomcut-api.vasia-pupkin1003.workers.dev/api/auth/login \
  -H "Content-Type: application/json" -d '{"password":"..."}' | jq -r .token)
curl -s https://artyomcut-api.vasia-pupkin1003.workers.dev/api/bookings \
  -H "Authorization: Bearer $TOKEN"
```

## Тесты

Логика проверена на моках KV (34 проверки): валидация, гонка на один слот,
параллельные записи на разные слоты, удаление, миграция старого формата,
расписание, отзывы, CORS, коды ответов.
