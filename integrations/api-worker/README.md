# Воркер API (artyomcut-api)

Здесь лежит обновлённый код воркера. Секретов в нём нет: пароль админки и
хранилища задаются в настройках Cloudflare (переменные и биндинги).

## Что изменилось по сравнению с прежней версией

1. **Правильные коды ошибок.** Невалидные данные (пустое имя, прошедшая дата,
   выходной, время вне графика, кривой JSON) возвращают `400` с понятным текстом,
   а не `500 Internal server error`. Дубликат слота — `409`.
2. **Записи больше не теряются.** Раньше все записи хранились одним JSON-списком в
   одном ключе KV: две одновременные записи перезаписывали друг друга, и одна
   терялась (оба клиента при этом видели «успех»).
   Теперь каждая запись — отдельный объект в R2 (`bookings/<дата>/<время>/<id>.json`),
   а слот занимается ключом KV `slot:<дата>:<время>` с подтверждением. При
   одновременной записи на один слот ровно один получает `200`, остальные —
   `409 «Это время уже занято»`.
3. **Запись видна сразу.** R2 строго консистентен, поэтому админка и `/api/booked`
   видят новую запись немедленно, без задержки в минуту, которая есть у `list()` в KV.
4. **Совместимость.** Старый ключ `bookings` и ключи `booking:<id>` один раз
   переносятся в R2 при первом запросе. Админка и `/api/booked` работают как раньше,
   фронтенд менять не нужно.

## Как задеплоить

1. Cloudflare Dashboard → **Workers & Pages** → `artyomcut-api`.
2. **Edit code** (Quick edit).
3. Выделить весь код в редакторе → вставить содержимое `worker.js` целиком.
4. **Deploy** (Save and deploy).

Биндинги (`ARTYOMCUT_DATA` — KV, `ARTYOMCUT_BUCKET` — R2) и переменную
`ADMIN_PASSWORD` трогать не нужно: они в настройках воркера, а не в коде.

## Проверка после деплоя

```bash
# невалидные данные → 400
curl -i -X POST https://artyomcut-api.vasia-pupkin1003.workers.dev/api/bookings \
  -H "Content-Type: application/json" -d '{}'

# запись → сразу видна
curl -s "https://artyomcut-api.vasia-pupkin1003.workers.dev/api/booked?date=2026-12-15"
```

## Тесты

Логика проверена на моках KV и R2 (36 проверок): валидация, гонка на один слот,
параллельные записи на разные слоты, мгновенная видимость, удаление, миграция
старого формата, расписание, отзывы, CORS, коды ответов.
