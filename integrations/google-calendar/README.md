# Записи → ваш Google Календарь

Как это должно работать: клиент записался → запись сразу появилась в админке → в течение 5 минут событие появилось в **вашем** Google Календаре.

## Что уже работает

- **Админка:** список записей обновляется сам раз в 30 секунд (и при возврате на вкладку) — перезагружать страницу не нужно.
- **Клиенту** после записи показываются кнопки «Добавить в Google Календарь» и «Скачать .ics» — это приятный бонус, к вашему календарю отношения не имеет.
- **Вам в админке** у каждой записи есть ссылка «В КАЛЕНДАРЬ» — добавить одно событие вручную, если нужно прямо сейчас.

## Автоматически в ваш календарь — 2 варианта

### Вариант 1 (рекомендуемый): Google Apps Script

Ничего устанавливать не нужно, всё живёт в вашем Google-аккаунте. 5 минут настройки.

1. Откройте https://script.google.com → **Новый проект**.
2. Сотрите код-заглушку и вставьте содержимое файла `apps-script/Code.gs` (лежит рядом).
   Готовый файл с уже вписанным паролем: `Мои сайты\google-calendar-sync.gs`.
3. В блоке `CONFIG` проверьте `ADMIN_PASSWORD` — там должен быть пароль от админки сайта.
4. Сохраните (Ctrl+S). Вверху выберите функцию **`install`** → **Выполнить**.
5. Google спросит разрешение на доступ к календарю → **Разрешить** (появится «Google не проверял приложение» → «Дополнительные настройки» → «Перейти»).
6. Всё. В логе будет `{"total":0,...}` — значит, синхронизация включена.

Дальше скрипт сам просыпается каждые 5 минут: новые записи добавляются, изменённые обновляются, удалённые удаляются из календаря.

**Другой календарь.** Если события должны попадать не в основной календарь, укажите его ID в `CALENDAR_ID` (Google Календарь → у календаря «⋮» → Настройки → «Идентификатор календаря», вида `xxxx@group.calendar.google.com`).

**Проверить вручную.** В редакторе выберите функцию `syncBookings` → «Выполнить» → в логе будет отчёт `{total, created, updated, removed}`.

**Выключить.** В Apps Script: «Триггеры» (значок будильника) → удалить триггер `syncBookings`.

**Важно.** Пароль от админки хранится только в вашем личном скрипте Google (и в локальном файле рядом с сайтом). В публичный репозиторий он не попадает.

### Вариант 2: отдельный Cloudflare Worker + сервисный аккаунт Google

Для тех, у кого уже есть Cloudflare CLI. Файлы: `calendar-sync.js`, `wrangler.toml.example`.

1. Google Cloud → включить Calendar API → создать сервисный аккаунт → скачать JSON-ключ.
2. В Google Календаре дать доступ `client_email` из ключа с правами «Изменение событий».
3. `wrangler kv namespace create SYNC_STATE`, вписать ID в `wrangler.toml`.
4. Секреты: `AC_ADMIN_PASSWORD`, `GOOGLE_CLIENT_EMAIL`, `GOOGLE_PRIVATE_KEY`, `GOOGLE_CALENDAR_ID`, `TRIGGER_SECRET`.
5. `wrangler deploy` — воркер запускается по cron каждые 5 минут.

Оба варианта не дублируют события: связка «запись → событие» хранится в Script Properties / KV.

## Нюансы

- Часовой пояс — `Europe/Madrid`, длительность события — 60 минут (меняется в `DURATION_MIN`).
- В событии: услуга в заголовке, имя и телефон в описании, адрес в поле «Место».
- Если поменяете пароль админки — обновите его в `CONFIG.ADMIN_PASSWORD` (или в секретах воркера).
- Одновременные записи на один слот — отдельная проблема бэкенда API, к синхронизации не относится.
